I want to build a modern, mobile-first prototype for a redesigned Newport News Housing Hub website. This is a college design-thinking project for the City of Newport News. The website is a concept only—it does not need a backend or database, but it should look like a real, production-quality government service that appeals to younger adults (ages 18–35).

Overall Design
Clean, modern UI inspired by Zillow, Rocket Mortgage, Airbnb, Apple, and the Charlotte, NC Housing Services website.
Avoid the typical outdated government website look.
Mobile-first and fully responsive.
Use HTML, CSS, and JavaScript.
Use Bootstrap 5 where appropriate.
Smooth scrolling and subtle animations.
Rounded cards, soft shadows, modern spacing, and professional typography.
Primary colors: navy blue, white, teal accents, and a small gold accent color.
